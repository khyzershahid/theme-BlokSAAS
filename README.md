# BlokSAAS Theme

A modern, responsive SaaS landing page theme built with **React** and **Vite**. Clean layout, fast load times, and easy to customize for your own product.

**🔗 Live Demo:** [theme-blok-saas.vercel.app](https://theme-blok-saas.vercel.app)

---

## 🚀 Features

- **Modern UI/UX:** Clean layouts and a professional look tailored for SaaS products
- **Fully Responsive:** Works across desktop, tablet, and mobile screens
- **Fast & Lightweight:** Powered by Vite for instant dev server startup and optimized builds
- **Component-Based:** Built with React, so sections are easy to edit, reorder, or reuse
- **Easy to Customize:** Update content, colors, and styles to match your brand

---

## 🧰 Tech Stack

- [React](https://react.dev/) 19
- [Vite](https://vitejs.dev/)
- HTML5 & CSS3
- Deployed on [Vercel](https://vercel.com/)

## 🛠️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm (comes with Node.js)

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/khyzershahid/theme-BlokSAAS.git
   ```

2. **Go to the project folder**

   ```bash
   cd theme-BlokSAAS
   ```

3. **Install dependencies**

   ```bash
   npm install
   ```

4. **Start the development server**

   ```bash
   npm run dev
   ```

   Then open the local URL shown in your terminal (usually `http://localhost:5173`).

## 🎨 Customization

- **Content:** Edit the components inside the `src/` folder to change text, headings, links, and sections.
- **Styles:** Update the stylesheets in `src/` to change colors, fonts, and spacing.
- **Page title & meta tags:** Edit `index.html`.

---

## 🌐 Deployment

This project is deployed on Vercel, but it works on any static hosting platform.

1. Run the build command:

   ```bash
   npm run build
   ```

2. Upload the generated `dist/` folder to your host (Vercel, Netlify, GitHub Pages, etc.).

For Vercel, you can also import the GitHub repo directly. It detects Vite automatically.
